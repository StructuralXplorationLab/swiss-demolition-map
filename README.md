# Swiss Building Demolition Risk Map (2027–2030)

An interactive web map visualizing predicted building demolition risks across Switzerland for the period 2027–2030.

The map displays buildings ranked by their predicted demolition risk, allowing users to explore the top 0.1%, 0.5%, 1%, 5%, and 10% of buildings nationwide.

The predictions are generated using a machine learning model trained on historical Swiss building data and various features from publicly available datasets.

The website supports English, German, and French and provides multiple basemap options.

**Disclaimer:** These predictions are estimates, not confirmed demolition plans. A high risk score does not mean that a building will necessarily be demolished.

**Dataset:** https://doi.org/10.5281/zenodo.23669030

**Interactive map:** https://structuralxplorationlab.github.io/swiss-demolition-map/
